# ศูนย์ CCTV ภ.จว.นราธิวาส

เว็บแอปต้นแบบสำหรับรวบรวม ติดตาม และวิเคราะห์ข้อมูลกล้อง CCTV เหตุการณ์ พื้นที่ บุคคล รถ และภารกิจในพื้นที่จังหวัดนราธิวาส

## เปิดใช้งาน

- ระบบ: <https://useman02406-afk.github.io/cctv-narathiwat/outputs/login.html>
- หน้าแรกหลังเข้าสู่ระบบ: <https://useman02406-afk.github.io/cctv-narathiwat/outputs/home.html>
- ระบบเป็นส่วนตัว ผู้ใช้งานต้องผ่านการยืนยันตัวตนและมีบัญชีที่เปิดใช้งาน

## โมดูลหลัก 12 หมวด

1. ภาพรวมศูนย์
2. ภาพรวม สภ.
3. ข้อมูลกล้อง CCTV
4. เหตุความมั่นคง
5. พื้นที่เศรษฐกิจ
6. พื้นที่เสี่ยง / เฝ้าระวัง
7. ข้อมูลบุคคล
8. รถแจ้งเตือน / พบรถ
9. วิเคราะห์พื้นที่ภารกิจ
10. ค้นหาบ้าน
11. ไทม์ไลน์สืบสวน
12. ศูนย์รายงาน

ทุกหน้าหลักมีปุ่ม **เมนู 12 หมวด** สำหรับเปิดโมดูลอื่นโดยไม่ต้องกลับหน้าแรก รองรับเมาส์ คีย์บอร์ด โปรแกรมอ่านหน้าจอ และหน้าจอขนาดเล็ก

## บทบาทผู้ใช้งาน

| บทบาท | ขอบเขตโดยสรุป |
|---|---|
| ADMIN | ดูและจัดการข้อมูล จัดการบัญชี หมวดหมู่ และการตั้งค่าที่ได้รับอนุญาต |
| OFFICER | ดูและบันทึกหรือแก้ไขข้อมูลตามนโยบายของแต่ละโมดูล |
| VIEWER | ดูและค้นหาข้อมูล ไม่มีสิทธิ์เปลี่ยนแปลงข้อมูล |
